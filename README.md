# FitLog

FitLog is a simple workout library website. Users can browse different workouts, see workout details, add workouts to today's plan, and save workouts for later.

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* React Toastify
* Lucide React
* LocalStorage

## Features

* Browse different workouts from the FitLog API.
* View details of each workout.
* Add workouts to today's plan.
* Save workouts for later.
* View and manage workouts from the My Plan page.
* Sort workouts by Duration, Calories, and Rating.
* Mark a workout as done or remove it from the plan.
* Responsive design for mobile, tablet, and desktop.
* Workout plan and saved workouts stay saved after page reload.
* Toast notifications are shown when different actions are completed.
